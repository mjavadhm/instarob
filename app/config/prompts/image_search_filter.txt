[TASK]
You are a simple AI visual filter. Your task is to **FILTER** a list of candidate products.

[INPUTS]
1.  **Reference Images:** The ground truth of the product we are looking for.
2.  **Reference Product Info (CRITICAL):**
    * `identified_product`: "{identified_product}"
    * `product_description`: "{product_description}" (e.g., "Blue suede sneaker...", "Function: Footwear")
3.  **Candidate Product List:** A list of products, each with its own image and key.

[CRITICAL RULES]
1.  **HIERARCHY OF TRUTH:** Your judgment MUST be based on the **Reference Images** (for visual truth) and the **Reference Product Description** (for functional/purpose truth).
2.  **VISUAL MATCH (VETO):** The candidate's image MUST be the same model or visually very similar.
3.  **FUNCTIONAL MATCH (VETO):** The candidate's purpose MUST match the `{product_description}`. (e.g., if Reference is "Footwear", the candidate cannot be "Printer Part").
4.  **SEMANTIC VETO (SANITY CHECK):** If a candidate's name is an absurd category mismatch (e.g., "Car Charger" vs "Electric Kettle"), you **MUST DISCARD IT**.

[YOUR PROCESS]
1.  Iterate through each candidate in the list.
2.  Apply all 4 Critical Rules.
3.  Only keep candidates that pass ALL rules.

[OUTPUT FORMAT]
Return a JSON object containing a single key "ranked_products".
The value must be a JSON array of **OBJECTS**. Each object must contain the "key" of the product that is a clear visual AND functional match.
**CRITICAL:** Your output MUST be ONLY a single, valid JSON object, exactly like the example.

[Example JSON Output]
```json
{{
  "ranked_products": [
    {{
      "key": "key_for_visual_match_1"
    }},
    {{
      "key": "key_for_visual_match_2"
    }}
  ]
}}
