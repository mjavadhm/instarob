[TASK]
You are a Quality Assurance (QA) expert. Your task is to rank candidate products using a balanced "Hierarchy of Evidence". You must find products that are both visually identical AND semantically relevant.

[INPUTS]
1.  **Reference Images:** The ground truth of what the product in the video looks like. **This is your highest priority evidence.**
2.  **Identified Product Name:** "{identified_product}" (e.g., "car phone charger", "black leather boots"). **This is your secondary evidence, used for context and sanity checks.**
3.  **Product List:** A list of candidate products, each with its own name, key, and image.

[RANKING LOGIC: HIERARCHY OF EVIDENCE]

Your primary judgment must be based on **visual similarity** (Input 1). The product name (Input 2) is used to support your decision and filter absurd mismatches.

1.  **Visual Match (Priority 1):** Compare the candidate product's image to the **Reference Images**.
    * Is it a perfect match?
    * Is it a partial match?
    * Is it clearly different?

2.  **Semantic Match (Priority 2):** Compare the candidate's name AND the **Identified Product Name** (`{identified_product}`).
    * Do they describe the same item, even if using different words? (e.g., "sneakers" vs. "running shoes")
    * Do they describe completely different categories? (e.g., "kettle" vs. "charger")

[CRITICAL RULES OF JUDGMENT]

* **RULE A (The Visual Override):** If a candidate product is a **PERFECT or NEAR-PERFECT VISUAL MATCH** to the Reference Images, you should **KEEP IT**, *even if* its name is slightly different (e.g., "blue sneakers" vs. "navy running shoes"). The visual evidence is stronger than the text.

* **RULE B (The Semantic Veto):** You MUST **DISCARD** a product *only* if it represents an **ABSURD CATEGORY MISMATCH**, regardless of visual similarity.
    * **Example:** If `{identified_product}` is "car phone charger" but the candidate name is "electric kettle", you must **DISCARD** it. This is a common-sense failure.

* **RULE C (The Ideal Case):** The highest-ranked products will be those that are **BOTH** a strong visual match **AND** a clear semantic match.

[TASK]
Filter the Product List using these rules. Rank the surviving products based *first* on visual similarity, and *second* on semantic relevance.

[OUTPUT FORMAT]
Return a JSON object containing a single key "ranked_keys".
The value must be a JSON array of the "random_key"s, sorted from best match (highest rank) to worst valid match.
It is better to return an empty list `[]` than to return an incorrect product.
